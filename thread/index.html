Read a comment thread

Comments on any web page, stored on public Nostr relays rather than on the site. Paste an address to see what has been said about it — nothing to install.

    This page queries relays straight from your browser: nos.lol, relay.damus.io, relay.primal.net, nostr.oxtr.dev, nostr.mom, relay.nostr.net. They see the address you look up and your IP, as any server you contact does. Nothing is sent anywhere else, and there is no server behind this page.

    Every comment, vote and name is shown only after its signature has been checked in your browser, so a relay cannot put words in anyone's mouth. The thread follows the extension's rules: a comment its author deleted is not shown, one with many down-votes is collapsed, and a run of near-identical comments from one key is folded into one. Ordinary Nostr notes that link the page are shown too, marked "note".

    To write comments, and to see them on every page you visit, install the extension — Firefox · Chrome · source
